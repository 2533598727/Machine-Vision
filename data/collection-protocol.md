# 采集与标注操作规范

本文件是综述第5节的执行补充，不计入综述正文字数。所有数量均为计划目标；仓库中没有已采集的学生图像、实验结果或真实标注。

## 1. 采集清单

- 原稿：作业、试卷、可移动板书、教学插图各6份。题目、文本与插图均原创；不要将同一模板的简单换字误算为独立原稿。
- 设备：两台不同品牌手机，拍摄时填写真实型号，尽量支持手动曝光和RAW。
- 地点：教室、书房、实验室。每类原稿每地点2份；划分时兼顾地点，避免某一划分与地点完全重合。
- 每个原稿与设备组合拍摄5种光照：漫射日光、荧光灯、白炽灯、侧光加遮挡、日光与暖灯混合。白炽灯无法取得时，不能将暖色LED冒称白炽灯，应修订条件名称和光谱说明。
- 每个组合另拍1张均匀照明参考图，共240张场景图、48张参考图。文件格式副本、校准伴拍、20张预试拍、失败重拍及增强图不累计为独立样本。
- 同一原稿在同一位置完成两台设备和全部光照的成组采集，先后次序轮换，记录天气变化；便携板书便于同位参考。

建议编号：原稿 `HW01`、`EX01`、`BD01`、`IL01` 等；场景 `HW01_A_L01`；参考 `HW01_A_REF`。编号仅是规则示例，不是已存在记录。

## 2. 四天执行

| 时间 | 执行内容 | 验收产物 |
| --- | --- | --- |
| 第1天 | 原稿与授权检查、20张预试拍、校准分级阈值 | 固定的采集参数与标注说明 |
| 第2天 | 三处场地成组拍摄、现场查漏补拍 | 240张场景图及48张参考图 |
| 第3天 | 配准、掩膜、文本和区域标注 | 连续质量数值、标签和任务真值 |
| 第4天 | 独立复核、分歧裁决、划分和公开审查 | 审核记录及按原稿分组的清单 |

两人分工：一人主采集和主标注；另一人负责记录、配对校验及复核。手机、支架、灯具、色卡以借用为前提；不超过500元的预算仅覆盖纸张、遮挡板、打印与交通等耗材，不声称包含购置专业色卡或相机。

## 3. 拍摄与参考

1. 支架固定距离，完整取景，边界外留定位标记。前后保持纸张和板面形状不变；本批不把严重卷曲展开作为研究变量。
2. 同一原稿与设备的五个场景锁定对焦、曝光和白平衡，记录光圈、ISO、快门及固定白平衡设置。借助灯距、功率和漫射材料控制亮度，避免高光裁剪。
3. 关闭美颜、滤镜以及可以关闭的HDR和自动场景增强。无法关闭的局部色调处理必须记录，不能把JPEG的逆伽马值当作真实传感器响应。
4. 参考另用均匀高显色照明，灰卡设定白平衡、保留色卡核查。参考曝光可调整到不饱和且不过暗，不能逐幅依据待测算法输出重新调参考。
5. 八个中性灰块分布在内容区外的四角和四边中点，保持与文档同一平面；其反射率差异通过各自参考比值抵消。每种照明配置再拍同平面均匀灰板，检查中心照明；不以灰板替换真实文档样本。
6. 场景与同设备参考通过固定定位点估计单应性，在固定规范分辨率上评估定位点重投影RMSE。建议规范分辨率长边2400像素，正文的2像素阈值固定在此尺度使用，不在不同分辨率上混用。
7. 定位点RMSE不等于全文对齐误差，需再人工检查文字边缘；板面、纸张弯曲变化或无法对齐的成对样本返拍。所有算法共用同一几何变换、有效内容掩膜与重采样方式。
8. 算法输入、OCR及全图像素评估均裁去色卡、灰块和定位标记。灰块只用于退化标注；色卡校色结果作为独立校准质检记录，不作为给算法的额外已知答案。若测试显式依赖色卡的算法，须另设“有校准目标”协议，不能和无色卡算法混报。

参考的角色是同设备、固定流程的操作目标。高显色照明并不自动等于D65或绝对真值，设备间的色彩差异仍应分层报告。

## 4. 标注口径

`annotation-template.json` 中的 `null` 表示尚未测量，不等于0；`public_release_approved` 默认 `false`。每条实际场景记录填写一个同机参考ID，八个灰块分别保存对应场景与参考的亮度、Lab及有效像素数。

### 偏色

- 按实际ICC配置将场景与参考统一到同一色彩空间；计算本项目ΔE00时固定CIELAB的D65参考白点，禁止直接把RGB当Lab。
- 若原始配置或渲染方式不明，记录假设，不能声称得到绝对色度测量。RAW先用固定开发器、固定颜色矩阵和可追踪参数转换；不把sRGB固定矩阵直接施加到相机RGB。
- 灰块内避开边缘、噪声和反光，取稳健代表值，计算8个对应色差的中位数。标签：低 `<3`、中 `3至8（含端点）`、高 `>8`。
- 该ΔE包含L*差异，不是纯色相偏移。同时记录中位Δa*、Δb*及人工标签（偏暖、偏冷、偏绿、偏品红或空间混合），不由单一色差数值猜测色温。

### 光照不均

- 对第i个灰块计算 `q_i = Y_scene_i / Y_reference_i`，排除饱和及接近噪声底的块；八块不足时标记无效并复核，不默默填0。
- `U = std(q_i, ddof=0) / mean(q_i)`。标签：低 `<0.05`、中 `0.05至0.15（含端点）`、高 `>0.15`。
- RAW测量须先减黑电平并使用统一的线性亮度转换；只有JPEG时可按标准sRGB传递函数逆变换，再计算相对Y，同时记录 `inverse_srgb_approximation`。
- 另标注内容区域阴影掩膜及其面积占比；边缘八点无法完整表达内部局部阴影。混光情况下保留逐块Δa*、Δb*，不以全局均值掩盖局部偏色。
- 分级阈值为项目约定，先在20张预试拍中校准并冻结版本，不能查看测试效果后再调分级。

### 任务与质检

- 人工逐行转写文字，标明印刷、手写、公式、图表与批注区域；复杂公式单列，不将普通OCR无法识别公式解释为校色失败。
- 区域坐标统一到规范图像，保存 `[x_min, y_min, x_max, y_max]` 像素坐标；掩膜与图片同尺寸。
- 复核员检查全部隐私和参考配对，盲审至少48条场景质量标注，抽样覆盖设备、光照、内容与全部难例；48条随机样本之外的难例复核单独计数，避免混淆随机审查比例。
- 返拍条件：内容被裁、笔画不可辨、有效内容区任一通道达到编码上限的像素并集比例 `>1%`，或固定尺度定位点RMSE `>2 px`。RAW另按传感器白电平判饱和。
- 阴影强但文字可读不自动剔除；不能通过删除困难样本美化指标。替换样本保留匿名失败原因和版本号。
- 保存裁决前标签、裁决后标签与一致率。灰板伴拍、曝光、阈值版本和配准错误都进入复核记录。

## 5. 分组与评价

原稿是不可拆分单位，所有设备、光照、参考、模板衍生和增强跟随原稿。四个内容类别分别分配4/1/1稿到训练、验证、测试，合计16/4/4稿；场景160/40/40张，参考32/8/8张。先固定原稿清单和随机种子再开发算法。三处地点在各划分中尽量均衡，不能把相同原稿跨设备的照片当作独立内容样本。

基线包括原图、Gray World、稳健White Patch、多尺度Retinex、预训练白平衡网络和光照校正网络。比较全局校色、去阴影及二者组合；同一内容裁剪和几何处理用于所有组。240张图仅适合受限评估、交叉验证或小幅微调，不能支持从零训练大型网络或宣称广泛泛化。

- PSNR：相同[0,1] RGB编码、相同有效内容掩膜内计算MSE，精确相等时记为正无穷；公开颜色编码与重采样方法。
- SSIM：固定实现、窗口、`data_range=1`及颜色处理方式；只聚合窗口完整落在有效区域内的结果。
- ΔE00：报告灰块校准质检与内容区配对色差时分开命名。纸面和插图区需固定人工掩膜，阴影区单独汇总。
- OCR：版本、模型、字典、缩放及文本规范化规则全部冻结，CER采用总替换、删除、插入数除以参考字符总数。正则化不删除有语义的正负号、小数点或单位。
- 版面F1：固定区域类别和匹配规则，例如同类别一对一匹配且IoU≥0.5；报告整体及分类型结果。
- 统计：同时报告总体微平均与各原稿宏平均，按设备、照明和内容分层。重采样以原稿为单位而非240张相关照片，置信区间仅探索性使用；测试集只有4份原稿，必须披露估计不稳定。

不预先填写性能数字，也不把更高OCR分数直接解释为学生成绩、掌握程度或能力提升。
